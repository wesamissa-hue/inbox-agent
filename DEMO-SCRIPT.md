# Two-Minute Demo

**One-line intro:** Team Inbox is a customer-support workspace where an AI
agent reads incoming messages and replies directly in the conversation.

1. **0:00** Open [https://inbox-agent-rho.vercel.app](https://inbox-agent-rho.vercel.app).
2. **0:10** Create an account or sign in. If email confirmation is enabled,
   complete it before the demo.
3. **0:30** Show the inbox and click **+ New demo chat**.
4. **0:50** Send: “Hi, I placed an order yesterday. Could you check whether it
   has shipped?”
5. **1:10** Show the AI agent's reply arriving in the same thread.
6. **1:35** Using the pre-provisioned operator account with the trusted admin
   role, open Agent dashboard and point out recent decisions and handoffs.
7. **1:55** Close with: “Next, I’d add team-specific inbox permissions.”
